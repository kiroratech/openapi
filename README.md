# Kirora OpenAPI spec

`openapi.json` is the OpenAPI 3.1 spec for the Kirora API. The docs are at
https://kirora.io/docs/api.

The spec is generated from an internal source and published here automatically, so
pull requests aren't accepted. Report API or spec problems to support@kirora.io, and SDK
problems in that SDK's repo, such as [node-sdk](https://github.com/kiroratech/node-sdk).

To pin a version, use a commit's raw URL:

```
https://raw.githubusercontent.com/kiroratech/openapi/<commit>/openapi.json
```
